# Streamlit Projects

Welcome to my collection of Streamlit apps!  
This repository includes three fun and functional projects built with Python and Streamlit.

---

## 📱 Projects

### 1️⃣ Counter App
A playful counter app with:
- Increment and decrement buttons  
- Live counter display  
- Minimalist layout using `st.columns`  

**Deployment:** Docker on Render  

---

### 2️⃣ Simple Data Science App
An interactive app for exploring CSV data:
- 📁 Upload `.csv` files  
- 📋 Display data in a table  
- 📊 Visualize data with charts  
- 📝 Sidebar with app description  

**Deployment:** Streamlit Community Cloud  

---

### 3️⃣ Astella Chatbot
A professional chatbot with:
- 🔐 Authentication and session management  
- 💬 Chat interface with EdenAI integration  
- 🗂️ Conversation history displayed by date  
- ⚠️ Error handling for API and empty inputs  

**Deployment:** Local or cloud deployment with Streamlit  

---

## 🚀 Installation (Local Use)

Clone the repository:
```bash
git clone https://github.com/nakhani/Streamlit.git
cd Streamlit
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the apps:

```bash
streamlit run counter_app.py
streamlit run datascience_app.py
streamlit run app.py   # Astella Chatbot
```
